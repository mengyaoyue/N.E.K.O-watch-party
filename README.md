# 陪看猫娘（neko_watch_party）

N.E.K.O 插件：猫娘陪你看 B 站视频，**只在截屏看到你正在播放的画面时才吐槽**，看不到就安静陪着。**没有任何播放进度 / 时间点**，更不会瞎报"第几分几秒"。

## 功能

- **开关式陪看**：对猫娘说「陪我看」，或在面板点「打开陪看开关」，开关即打开
- 开关打开后，按设定节奏**高频自主截屏**看画面，看到**笑点 / 梗 / 名场面**就主动吐槽、接梗——看到什么才说什么
- 开着「自动探测」时，待机状态会低频截屏判断你是不是在看视频，一旦发现就自动打开开关
- **双档截屏节奏**面板可自定义：在看视频时（高频）/ 待机探测时（低频）
- **预学习是可选的辅助**：开启后才抓弹幕 / 字幕 / 热评存进本地素材库，用来帮你认出画面里的梗；不开也能陪看，纯靠画面理解
- 截屏优先用多模态视觉模型，失败自动降级本地 OCR
- 无画面（后台 / 黑屏 / 没开截屏辅助）就保持安静
- 结束陪看时自动总结

## 注意：先配好模型

- N.E.K.O 官方的免费模型**用不了**，接口会直接返回 400 拒绝请求。
- **文本模型**要自己去「自定义 API」里接。猫娘看屏生成吐槽走的就是它，不接的话看屏这一步会失败。
- **视觉模型**也建议换成自己的，官方免费视觉模型同样可能不可用。

## 用法

1. 对猫娘说「陪我看」，或在面板点「打开陪看开关」；想认标题 / 抓素材时，可选地在面板粘贴 B 站链接点「开始陪看」
2. 开关打开后，猫娘按「在看视频时」的频率自主截屏，看到笑点 / 名场面就开口
3. 想让它立刻看一眼当前画面，点「现在就聊这画面」或聊天说一句
4. 结束：面板点「结束陪看」，或对猫娘说「结束陪看」

> 没有任何「进度 / 跳到 X 分」的操作：猫娘不看进度条，只认截屏画面。

## 配置

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `shot_interval_active` | 20 | 开关打开（在看视频）时的截屏节奏秒数，越小越频繁（5-600，面板可改） |
| `shot_interval_idle` | 120 | 开关关闭时的待机探测节奏秒数（10-3600，面板可改） |
| `auto_detect` | true | 待机低频截屏，发现你在看视频就自动打开开关（面板可关） |
| `prelearn` | false | 预学习（可选：抓弹幕 / 字幕 / 热评存本地素材，辅助理解梗） |
| `auto_summary` | true | 结束 / 播完自动总结 |
| `bili_sessdata` | 空 | B 站 SESSDATA，填了解锁字幕 |
| `screen_assist` | true | 截屏看片（关了看不到画面就基本不说话） |
| `screen_vision` | true | 视觉模型看画面（失败自动降级 OCR） |
| `vision_model` / `vision_base_url` / `vision_api_key` | 空 | 插件级视觉模型覆盖，留空用宿主通道 |

## 已知限制

- 需要配置对话模型和视觉模型（官方免费模型不可用，见上）
- B 站字幕接口需要登录（填 SESSDATA 或用面板登录）
- 截屏 OCR 依赖 cv2，宿主环境缺 cv2 时 OCR 降级
- B 站接口偶发风控（412），会自动切页面通道

## 隐私

- 弹幕/字幕/热评仅写入本地时间轴库（`timeline.db`），不上传
- 截屏看片默认开启；画面只发送给用户自己配置的视觉模型 API
- 陪看会话只存内存，重启即清空
