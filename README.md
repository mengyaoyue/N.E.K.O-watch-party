# 陪看猫娘（neko_watch_party）

> 猫娘陪你刷B站：预习视频、读弹幕与字幕、按你的播放进度实时共情吐槽——笑、感动、同情、震惊、燃，她都会说出口喵。

- 版本：`0.3.5`｜作者：MENGYAOYUE
- 适用：N.E.K.O 插件运行时（SDK `>=0.1.0, <0.3.0`）
- 依赖：零第三方库（urllib + zlib + xml.etree；截屏辅助用宿主自带的 dxcam/rapidocr）

# ⚠️ 开始前必读（最重要）

**猫娘和你的视频播放器是两个独立进程**——她看不到你的播放器进度条。正确用法：

1. 面板粘贴链接（或聊天发「陪我看 <链接>」）→ 点开始
2. **等预习完成（约 10~30 秒，猫娘会回复"已开陪"）**
3. **再打开视频开始观看**
4. 进度不对时：面板填分钟数点「跳到」，或聊天说「跳到 X 分」——**瞬间对齐**，之后吐槽就跟着你的进度走喵！

## 玩法总览

| 步骤 | 说明 |
|------|------|
| 🔍 预习 | 抓视频信息 + 全量弹幕 + 热评 + **字幕时间轴**（配 SESSDATA），一次 LLM 调用生成全片陪看脚本 |
| 🎬 陪看 | 按进度到点推送反应（带 `[分:秒]` 和情绪表情），密度由你定（默认 3 条/分钟） |
| ⏱ 心跳 | 每 3 分钟结合台词/弹幕主动碎碎念一句看法 |
| 💬 互动 | 随时问「刚才那段什么梗」→ 读当前位置的台词/弹幕/画面现场解读 |
| 📊 总结 | 播完自动推送：弹幕高能时刻 TOP3 + 情绪分布 + 最后一次感慨 |
| 📺 同步播放窗口 | 面板一键打开猫娘控制的播放窗口：**直接读 video.currentTime，毫秒级完美同步**（暂停/拖动全感知），跳到 X 分时连播放器一起跳 |

## 三级数据链（抗风控）

1. **静态 API**（快）：view / dm/list.so / reply
2. **页面通道**：B站风控 412 时自动用真浏览器打开视频页，从 `__INITIAL_STATE__` 提取信息、页面内拉弹幕
3. **诚实报错**：都失败时明说"B站临时风控，歇几分钟再试"，绝不编数据

## 管理面板

插件管理的「面板」页内嵌控制台，右上角「打开界面」独立窗口：

- 粘贴链接直开陪看（部分环境无效时就用聊天，最稳）
- 实时会话状态：进度条、反应触发数、当前密度
- 「跳到 X 分」校准、「结束陪看」、「刚才那段」现场吐槽
- **反应密度自定义**：每分钟几条（1~10），保存持久化

## 配置（`[neko_watch_party]`）

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `reactions_per_minute` | 3 | 反应密度：每分钟几条（1-10，面板可改） |
| `reaction_count` | 10 | 反应数下限（短视频保底） |
| `auto_begin` | true | 预习完自动开始（关掉则等你说"开始看"） |
| `heartbeat_minutes` | 3 | 自发碎碎念间隔（0 关闭） |
| `auto_summary` | true | 播完自动总结 |
| `bili_sessdata` | 空 | 浏览器 F12 复制的 B站 SESSDATA，**填了解锁字幕模式** |
| `screen_assist` | false | 截屏辅助（截主屏 + 本地 OCR，让猫娘看见画面） |
| `screen_on_react` | true | 「刚才那段」时是否截屏 |
| `request_timeout` / `llm_timeout` / `poll_interval` | 15 / 45 / 2 | 请求与轮询超时 |

# ⚠️ 已知限制（诚实说明）

- **伪同步**：插件不知道播放器真实进度，按"你说开始的时间"推算；暂停/拖动后用 `跳到 X 分` 校准
- **字幕需要登录**：B站字幕接口对匿名请求返回空；把浏览器的 `SESSDATA` 填进配置即可解锁，否则自动走弹幕模式
- **多P视频**取链接里 `?p=N` 指定的分P
- 需要在 N.E.K.O 配置好对话模型（预习生成脚本用）
- B站接口偶发风控（412），插件会自动切页面通道，仍失败时明确报错，稍等即可

## 隐私

- 弹幕/评论/视频信息仅本地处理，不上传任何第三方
- 截屏辅助默认关闭；开启后 OCR 也在本地推理，文字不落盘不上传
- 陪看会话只存内存，重启即清空
