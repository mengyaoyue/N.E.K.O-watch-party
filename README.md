# 陪看猫娘（neko_watch_party）

N.E.K.O 插件：猫娘陪你看 B 站视频，按播放进度推送情绪反应。

## 功能

- 预习视频信息、弹幕、热评，生成全片陪看脚本
- 按播放进度到点推送反应（带时间戳和情绪）
- 截屏辅助：通过视觉模型或本地 OCR 读取画面
- 同步播放窗口：直接读取播放器进度，无需手动校准
- 面板可调截屏频率和反应密度
- 播完自动总结

## 注意：先配好模型

- N.E.K.O 官方的免费模型**用不了**，接口会直接返回 400 拒绝请求。
- **文本模型**要自己去「自定义 API」里接。本插件预习用的就是它，不接的话预习到生成陪看脚本这一步会失败。
- **视觉模型**也建议换成自己的，官方免费视觉模型同样可能不可用。

## 用法

1. 面板粘贴 B 站链接或 BV 号，点「开始陪看」
2. 等预习完成（约 10~30 秒）
3. 开始观看视频
4. 进度不同步时，面板填分钟数点「跳到」，或聊天说「跳到 X 分」

## 配置

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `reactions_per_minute` | 3 | 每分钟反应条数（1-10） |
| `reaction_count` | 10 | 反应数下限 |
| `auto_begin` | true | 预习完自动开始 |
| `heartbeat_minutes` | 3 | 自发碎碎念间隔（0 关闭） |
| `auto_summary` | true | 播完自动总结 |
| `bili_sessdata` | 空 | B 站 SESSDATA，填了解锁字幕 |
| `screen_assist` | false | 截屏辅助 |
| `screen_vision` | true | 视觉模型看画面 |
| `idle_probe_interval` | 180 | 非共享时截屏间隔（秒） |
| `playback_gate` | true | 播放门禁（无真实播放时暂停发稿） |
| `voice_input_detect` | true | 宿主语音输入检测（语音开=共享） |

## 已知限制

- 需要配置对话模型和视觉模型（官方免费模型不可用，见上）
- B 站字幕接口需要登录（填 SESSDATA 或用面板登录）
- 截屏 OCR 依赖 cv2，宿主环境缺 cv2 时 OCR 降级
- B 站接口偶发风控（412），会自动切页面通道

## 隐私

- 弹幕/评论/视频信息仅本地处理
- 截屏辅助默认关闭；开启后视觉模型调用走用户配置的 API
- 陪看会话只存内存，重启即清空
