# 陪看猫娘（neko_watch_party）

> 陪主人看B站视频：猫娘预习视频、读取全量弹幕与热评，按播放进度在对应时间点冒出来表达情绪——笑、感动、同情、震惊、吐槽，她都会说出口喵。

- 版本：`0.1.0`
- 作者：MENGYAOYUE
- 适用：N.E.K.O 插件运行时（SDK `>=0.1.0, <0.3.0`）
- 依赖：零第三方库（urllib + zlib + xml.etree）

## 玩法流程

1. **预习**：发B站链接或 BV 号 → 猫娘抓视频信息 + 全量弹幕（`x/v1/dm/list.so`，deflate XML）+ 热评（可降级），一次 LLM 调用生成全片"陪看脚本"（带时间戳的情绪反应点）
2. **开始**：说"开始看" → 猫娘按时间轴到点推送反应（`ctx.push_message`，带 `[分:秒]` 和情绪表情）
3. **校准**：暂停/拖进度后说"跳到 12 分" → 她立刻跟上
4. **互动**：随时问"刚才那段什么梗" → 她读当前位置附近的弹幕现场解读
5. **总结**：播完自动推送：弹幕高能时刻 TOP3（5 秒窗口密度）+ 猫娘情绪分布 + 最后一次感慨

## 入口（供自然语言命令/主 AI 跨插件调用）

| 入口 | 参数 | 说明 |
|------|------|------|
| `start_watch` | `video`（链接/BV号）, `begin_now` | 预习并（可选）立即开始 |
| `begin_watch` | — | 开始同步陪看 |
| `jump_to` | `minute` | 校准进度 |
| `react_now` | — | 当前位置现场反应 |
| `stop_watch` | — | 结束并总结 |
| `status` | — | 会话状态 |

## 配置（`[neko_watch_party]` 段）

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `reaction_count` | 10 | 全片反应条数（3-20） |
| `request_timeout` | 15 | B站接口请求超时（秒） |
| `llm_timeout` | 45 | 预习调用大模型超时（秒） |
| `poll_interval` | 2 | 时间轴轮询间隔（秒） |
| `auto_summary` | true | 播完自动总结 |
| `catgirl_name` / `master_name` | 猫娘 / 主人 | 文案称呼 |

## 降级与隐私

- 弹幕/评论接口失败时自动降级：LLM 脚本生成失败则改用"弹幕密度高能点"机械反应，玩法不中断
- 数据匿名读取（UA + buvid3），不使用你的B站账号，不落盘任何视频数据
- 陪看会话只存内存，重启即清空

## 已知边界（诚实说明）

- **伪同步**：插件不知道播放器真实进度，按"你说开始的时间"推算；暂停后用 `jump_to` 校准
- 多P视频取链接里 `?p=N` 指定的分P
- 需要在 N.E.K.O 配置好对话模型（预习要用）
